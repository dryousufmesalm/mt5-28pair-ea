# MT5 28-Pair EA v3

Multi-pair EA with YM Execute/Position; per-symbol TP/SL.

**Author:** Yousuf Mesalm | www.yousufmesalm.com | WhatsApp +201006179048 | Upwork: https://www.upwork.com/freelancers/youssefmesalm

## Requirements

MetaTrader 5. YM library in MQL5/Include/YM.

## Installation

Copy the mq5 file into MQL5/Experts/.

## Compilation

Compile in MetaEditor (F7). Include path must include terminal MQL5 folder.

## Usage

Attach to charts or use on multiple symbols. Configure per-symbol TP/SL and other inputs.
